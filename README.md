# 📚   Course Explorer

A lightweight and fast web application that helps users quickly find **  LMS course links** using either the **Course ID** or **Course Name**.

> **Disclaimer:** This project is an independent utility created for educational convenience. It only generates links to the official  LMS using Course IDs. It does **not** host, copy, modify, or distribute any course content.

---

## ✨ Features

* 🔍 Search by **Course ID**
* 📖 Search by **Course Name**
* ⚡ Instant search with fast rendering
* 📂 Open the course page directly
* 📑 Open the course Modules page
* 🔗 Copy Course Link
* 📋 Copy Modules Link
* 📱 Responsive design
* 🎨 Clean and lightweight UI
* 🚀 No frameworks required (Pure HTML, CSS & JavaScript)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/NishantRajora/Course-Explorer.git
```

### Open the project

Simply open **index.html** in your browser.

Or run a local server:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```

---

## 📄 Course Data Format

The project reads data from `course.csv`.

Example:

```csv
2963,Basic Computer Skills for Professionals
3011,Data Structures
4210,Machine Learning
```

Format:

```
CourseID,CourseName
```
