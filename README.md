## ✨ Features

* 🔍 Search by **Course ID**
* 📚 Search by **Course Name**
* ⚡ Instant search with optimized performance
* 📖 Open the official course page
* 📂 Open the course Modules page
* 🔗 Copy Course URL
* 📋 Copy Modules URL
* 📱 Fully responsive design
* 🎨 Clean and lightweight interface
* 🚀 Built with pure HTML, CSS and JavaScript
* 📄 Reads course data directly from a CSV file

---

## 📸 Preview

Search any course by entering its **Course ID** or **Course Name**.

Each result provides:

* 📖 Open Course
* 📂 Open Modules
* 🔗 Copy Course Link
* 📋 Copy Modules Link

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/NishantRajora/Course-Explorer.git
```

### Open the project

Open `index.html` directly in your browser.

Or run a local development server:

```bash
python -m http.server
```

Then visit:

```text
http://localhost:8000
```

---

## 📄 Course Data Format

The project loads course information from `course.csv`.

Example:

```csv
2963,Basic Computer Skills for Professionals
3011,Data Structures
4210,Machine Learning
```

Format:

```text
CourseID,CourseName
```

## ⚠️ Disclaimer

This website is an **independent utility** created for educational convenience.

* It only generates links to the **official NCU LMS** using Course IDs.
* It does **not** host, copy, modify, or redistribute any course content.
* All course materials remain the property of their respective owners.
* Access to courses depends on the permissions and authentication provided by the official NCU LMS.
